# ⚡ nanoGPT — GPT-2 from Scratch

> A from-scratch implementation of a GPT-2-style transformer, trained on the Tiny Shakespeare dataset. Built following Andrej Karpathy's [Let's build GPT](https://www.youtube.com/watch?v=kCc8FmEb1nY) lecture.

## 📌 Overview

This repo walks through building a **character-level GPT-2-style language model** entirely from scratch in PyTorch — no HuggingFace, no abstractions. The model learns the patterns of Shakespearean prose and generates new text in a similar style.

The implementation progresses from a simple bigram baseline all the way to a full multi-head self-attention transformer.

## 🏗️ Model Architecture

The `v2.py` transformer implements all the core GPT-2 building blocks from scratch:

- **Token + Positional Embeddings** — character-level vocabulary with learned position encodings
- **Multi-Head Self-Attention** — scaled dot-product attention with causal masking (decoder-only)
- **Feed-Forward Network** — two-layer MLP with ReLU activation per transformer block
- **Layer Normalisation** — pre-norm formulation
- **Stacked Transformer Blocks** — configurable depth

## 🚀 Getting Started

### Prerequisites

```bash
pip install torch
```

### Train the bigram baseline

```bash
python bigram.py
```

### Train the full GPT-2-style model

```bash
python v2.py
```

### Or run the end-to-end notebook

```bash
jupyter notebook character_level_nano_gpt_with_tinyshakespeare.ipynb
```

> A GPU is recommended for training `v2.py`. Training on CPU is possible but slow. Google Colab (T4/A100) works great.

## 🔑 Concepts Implemented

- Character-level tokenisation
- Bigram language modelling (baseline)
- Scaled dot-product self-attention
- Causal (masked) attention for autoregressive generation
- Multi-head attention
- Transformer blocks with residual connections
- Layer normalisation
- Temperature-based text generation / sampling
